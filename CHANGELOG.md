# Turboist v1.7.0

## New Features

- **Two-factor authentication (2FA)** — You can now secure your account with a
  TOTP authenticator app (Google Authenticator, Authy, etc.). Enable 2FA from
  the Security section in your account settings, scan the QR code, and confirm
  with a one-time code. You can disable 2FA at any time from the same section.

## Improvements

- Redesigned Security section with a cleaner, more intuitive interface for
  managing account security settings.
- Faster login — password hashing performance has been tuned for a snappier
  sign-in experience without compromising security.
